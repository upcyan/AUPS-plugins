# cyansecengine — 青·擎

青·擎是 AUPS 的统一安全编排插件，提供一个安全总览入口，并把具体操作
分发给能力引擎：

- 防火墙：通过公共契约调用 `secgroup` 的 nftables provider；
- WAF：读取核心 WAF 规则、IP 黑名单、限流和订阅状态；
- 漏洞检测：调用 `vuln` provider；
- 主机安全：汇总 `rkhunter`、`lmd`、`yara` 等能力插件；
- 实时防护：展示核心 `rtguard` 状态。

青·擎不复制各引擎的数据目录。已有规则、报告和订阅继续由对应引擎管理，
这样升级或停用青·擎不会删除安全数据。

## 依赖

`secgroup` 是防火墙 provider 的硬依赖；漏洞检测和主机安全引擎为可选依赖，
可在插件中心分别安装。启用前仍会执行插件完整性检查和管理员运行确认。
